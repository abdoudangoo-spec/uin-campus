# UIN-CAMPUS
## Utilisation
UIN-CAMPUS est un systeme de gestion estudiantine concu pour L'Universite Islamique Au Niger
### Outils et Version
Outils                      Version
g++                         15.2.0-16        
clang++                     21.1.8 (13)
cmake                       4.4.5
ninja                       1.13.2
gdb                         18.1-3
git                         2.53.0
#### Construction et Execution
cd uin-campus
cmake --preset debug
cmake --build --preset debug
./build/debug/uin-campus
